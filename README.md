**Breach Point** — a Three.js first-person shooter built for the [threejs-fps-02](https://make.fun/bounty/threejs-fps-02) bounty. Pointer-lock movement (WASD + mouse look), shooting, enemy bots, objective zones, and a full HUD (timer, team score, health, ammo).

## Run

```
npx serve .
```

Open the served URL in a modern browser, click to lock the pointer, and play.
